# Security

Neruvalo is in the design stage. No production release exists, and the proposed cryptographic design has not undergone an independent audit.

Do not use a prototype for real passwords, payment cards, wallet recovery phrases or private keys.

## Reporting a vulnerability

Do not disclose exploitable vulnerabilities or real secrets in public issues.

If GitHub private vulnerability reporting is enabled, use **Security → Report a vulnerability**. Otherwise, contact the repository owner through a privately available contact method; a dedicated reporting address has not yet been established.

Private reporting availability and the supported-version policy must be established before a production release. This file does not claim those GitHub settings have already been enabled.
